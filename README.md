# WAYS Sport — prototype immersif

Prototype Next.js du site WAYS Levallois.

## Concept
- arrivée devant les portes du club ;
- ouverture des portes au scroll ;
- entrée progressive dans l'univers WAYS ;
- parcours TRAIN → STUDIOS → RECOVER → LIVE → MEMBERSHIPS ;
- SEO local Levallois ;
- données structurées JSON-LD ;
- responsive mobile ;
- support `prefers-reduced-motion`.

## Lancer en local
```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000

## À remplacer avant mise en production
1. Photos Unsplash → photos/vidéos réelles WAYS.
2. Logo typographique temporaire → SVG officiel WAYS.
3. Adresse exacte.
4. Horaires.
5. E-mail / formulaire CRM.
6. Tarifs définitifs.
7. Planning réel.
8. Mentions légales / politique de confidentialité / cookies.
9. Domaine définitif.
